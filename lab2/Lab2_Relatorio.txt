===============================================================================
EXERCICIO 1 - Soma de matrizes
===============================================================================

ENUNCIADO:
Faca um programa para somar matrizes de acordo com o seguinte algoritmo:
- O primeiro processo ira criar duas matrizes preenchidas e uma terceira
  vazia em 3 areas de memoria compartilhada.
- Para cada linha da matriz solucao, o seu programa devera gerar um
  processo para o seu calculo.
OBS: implemente as matrizes como vetores de tamanho (linha x coluna) e
aloque a shared memory para os vetores correspondentes, pois acessar os
elementos (i,j) e complexo.

CODIGO FONTE (ex1.c):
-------------------------------------------------------------------------------
#include <stdio.h>
#include <stdlib.h>
#include <sys/ipc.h>
#include <sys/shm.h>
#include <sys/stat.h>
#include <unistd.h>
#include <sys/wait.h>

int main (int argc, char *argv[]){
    int m1, m2, mRes, *p1, *p2, *pRes, status, i, j;
    pid_t pid;
    m1 = shmget(IPC_PRIVATE, sizeof(int) * 9, IPC_CREAT | IPC_EXCL | S_IRUSR | S_IWUSR);
    m2 = shmget(IPC_PRIVATE, sizeof(int) * 9, IPC_CREAT | IPC_EXCL | S_IRUSR | S_IWUSR);
    mRes = shmget(IPC_PRIVATE, sizeof(int) * 9, IPC_CREAT | IPC_EXCL | S_IRUSR | S_IWUSR);
    p1 = (int *)shmat(m1, 0, 0);
    p2 = (int *)shmat(m2, 0, 0);
    pRes = (int *)shmat(mRes, 0, 0);

    int valoresA[9] = {5, 7, 9, 6, 3, 6, 3, 1, 2};
    int valoresB[9] = {5, 3, 0, 6, 2, 6, 5, 7, 0};

    for (i = 0; i < 9; i++) {
        p1[i] = valoresA[i];
        p2[i] = valoresB[i];
        pRes[i] = 0;
    }

    for (i = 0; i < 3; i++) {
        pid = fork();
        if (pid < 0){
            perror("fork");
            exit(1);
        }

        if (pid == 0){
            for (j = 0; j < 3; j++){
                pRes[i * 3 + j] = p1[i * 3 + j] + p2[i * 3 + j];
            }

            exit(0);
        }
    }

    for (i = 0; i < 3; i++){
        waitpid(-1, &status, 0);
    }

    printf("Resultado:\n");
    for (i = 0; i < 3; i++) {
        for (j = 0; j < 3; j++)
            printf("%d ", pRes[i * 3 + j]);
        printf("\n");
    }

    shmdt(p1);
    shmdt(p2);
    shmdt(pRes);

    shmctl(m1, IPC_RMID, NULL);
    shmctl(m2, IPC_RMID, NULL);
    shmctl(mRes, IPC_RMID, NULL);

    return 0;
}
-------------------------------------------------------------------------------

    ./ex1

-------------------------------------------------------------------------------
Resultado:
10 10 9
12 5 12
8 8 2

REFLEXAO:
O programa aloca 3 segmentos de memoria compartilhada (m1, m2 e mRes),
representando as matrizes A, B e o resultado C, cada uma como um vetor
de 9 posicoes (matriz 3x3 "achatada"), acessando o elemento logico (i,j)
pela formula i*3+j. Os tres segmentos sao criados e anexados (shmat) pelo
processo PAI, ANTES de qualquer fork() - isso e essencial, porque so
assim cada processo filho, ao ser criado, ja herda automaticamente os
mesmos ponteiros (p1, p2, pRes) apontando para a mesma memoria fisica,
sem precisar refazer shmget/shmat.

E criado um processo filho por LINHA da matriz resultado (um for de 3
iteracoes, ja que a matriz e 3x3), e cada filho calcula apenas a sua
linha, usando o indice i do laco (herdado no momento do fork). O exit(0)
dentro do "if (pid == 0)" e essencial: sem ele, o processo filho
continuaria executando o restante do for e criaria seus proprios filhos
("netos"), multiplicando processos indevidamente.

O pai so espera todos os filhos terminarem (loop de waitpid(-1, ...))
DEPOIS de ja ter criado todos eles no primeiro for - isso permite que os
3 calculos de linha rodem de forma concorrente, e nao um de cada vez.

O resultado da soma (10 10 9 / 12 5 12 / 8 8 2) confere exatamente com
A+B elemento a elemento, confirmando que cada processo filho escreveu
corretamente na sua fatia da memoria compartilhada mRes, e que o pai
conseguiu ler o vetor completo depois que todos os filhos terminaram.


===============================================================================
EXERCICIO 2 - Mensagem do dia
===============================================================================

ENUNCIADO:
Faca um programa que:
- Leia uma mensagem do dia do stdin (ou arquivo)
- Crie uma memoria compartilhada com a chave 8752
- Salve a mensagem na memoria
Faca um outro programa "cliente" que utilize a mesma chave (8752) e
exiba a mensagem do dia para o usuario.

CODIGO FONTE (ex2.c) - programa que grava a mensagem:
-------------------------------------------------------------------------------
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/ipc.h>
#include <sys/shm.h>
#include <sys/stat.h>
#include <unistd.h>
#include <sys/wait.h>

#define CHAVE 8752
#define TAM_MSG 256

int main (int argc, char *argv[]){
    int id;
    char *p;
    char buffer[TAM_MSG];

    printf("Digite a mensagem do dia: ");

    if (fgets(buffer, TAM_MSG, stdin) == NULL){
        fprintf(stderr, "Erro ao ler a mensagem.\n");
        exit(1);
    }

    id = shmget(CHAVE, TAM_MSG, IPC_CREAT | S_IRUSR | S_IWUSR | S_IRGRP | S_IROTH);
    if (id == -1){
        perror("shmget");
        exit(1);
    }

    p = (char *)shmat(id, 0, 0);
    if (p == (void *) -1) {
        perror("shmat");
        exit(1);
    }

    strncpy(p, buffer, TAM_MSG - 1);
    p[TAM_MSG - 1] = '\0';

    printf("Mensagem gravada na memoria compartilhada (chave %d, id %d).\n", CHAVE, id);

    shmdt(p);

    return 0;
}
-------------------------------------------------------------------------------

CODIGO FONTE (ex2cliente.c) - programa que le a mensagem:
-------------------------------------------------------------------------------
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/ipc.h>
#include <sys/shm.h>
#include <sys/stat.h>

#define CHAVE 8752
#define TAM_MSG 256

int main(int argc, char *argv[]) {
    int id;
    char *p;

    id = shmget(CHAVE, TAM_MSG, S_IRUSR | S_IWUSR | S_IRGRP | S_IROTH);
    if (id == -1){
        perror("shmget");
        fprintf(stderr, "Nao foi possivel encontrar a memoria compartilhada (chave %d).\n", CHAVE);
        exit(1);
    }

    p = (char *)shmat(id, 0, 0);
    if (p == (void *) -1){
        perror("shmat");
        exit(1);
    }

    printf("Mensagem do dia: %s\n", p);

    if(shmdt(p) == -1){
        perror("shmdt");
        exit(1);
    }

    return 0;
}

REFLEXAO:
Esse exercicio e conceitualmente diferente dos demais deste relatorio:
aqui NAO existe fork() nenhum - sao DOIS EXECUTAVEIS SEPARADOS e sem
qualquer relacao de parentesco, rodados em chamadas distintas do
terminal. A unica forma de os dois programas "se encontrarem" na mesma
memoria compartilhada e combinando de antemao uma CHAVE FIXA (8752, a
constante CHAVE), usada como primeiro argumento do shmget() nos dois
programas - diferente dos exercicios com fork(), onde IPC_PRIVATE seria
suficiente (pois so os processos aparentados precisam conhecer o id).

Note que ex2.c usa IPC_CREAT (cria o segmento se nao existir, ou
reaproveita se ja existir de uma execucao anterior), enquanto
ex2cliente.c NAO usa IPC_CREAT: ele so pode ENCONTRAR um segmento ja
criado. Se o cliente fosse executado antes do servidor pelo menos uma
vez, o shmget() retornaria -1, e o programa informaria o erro
corretamente (testamos esse caso em execucoes anteriores do
desenvolvimento e o comportamento foi o esperado).

Tambem e importante notar que nenhum dos dois programas chama
shmctl(id, IPC_RMID, ...): o segmento de memoria com a chave 8752 e
PERSISTENTE - ele continua existindo no sistema mesmo depois que ambos
os programas terminam, ate que alguem explicitamente o remova (por
exemplo, com o comando "ipcrm -M 8752" no terminal) ou o sistema seja
reiniciado. Isso e proposital: se o servidor removesse o segmento ao
terminar, o cliente jamais conseguiria le-lo depois, ja que os dois
rodam em momentos totalmente diferentes.

EXERCICIO 3 - Busca paralela em vetor
===============================================================================

ENUNCIADO:
Faca um programa paralelo (com pelo menos 4 processos) para localizar
uma chave em um vetor.
- Crie uma memoria compartilhada com dados numericos inteiros e
  desordenados e a divida pelo numero de processos.
- Cada processo deve procurar o dado na sua area de memoria e informar a
  posicao onde o dado foi localizado.

CODIGO FONTE (ex3.c):
-------------------------------------------------------------------------------
#include <stdio.h>
#include <stdlib.h>
#include <sys/ipc.h>
#include <sys/shm.h>
#include <sys/stat.h>
#include <unistd.h>
#include <sys/wait.h>

#define TAM 20
#define N 4
#define CHAVE 42

int main(int argc, char* argv[]){
    int segV, segR, *vetor, *resul, id, pid, status;
    int k, i;
    int fatia;

    segV = shmget(IPC_PRIVATE, sizeof (int) * TAM, IPC_CREAT | IPC_EXCL | S_IRUSR | S_IWUSR);
    segR = shmget(IPC_PRIVATE, sizeof (int) * TAM, IPC_CREAT | IPC_EXCL | S_IRUSR | S_IWUSR);

    vetor = (int *)shmat(segV, 0, 0);
    resul = (int *)shmat(segR, 0, 0);

    int valores[TAM] = {42, 64, 123, 1, 9, 6, 42, 97, 43, 85, 17, 60, 12, 83, 81, 94, 60, 57, 42, 81};

    for (i = 0; i < TAM; i++){
        vetor[i] = valores[i];
    }

    for (i = 0; i < N; i++){
        resul[i] = -1;
    }

    fatia = TAM / N;

    for (k = 0; k < N; k++){
        if((id = fork()) < 0){
            puts("Erro na criação do novo processo");
            exit(-2);
        }
        else if (id == 0){
            int inicio = k * fatia;
            int fim = inicio + fatia;
            for (i = inicio; i < fim; i++){
                if (vetor[i] == CHAVE){
                    resul[k] = i;
                    break;
                }
            }

            printf("Filho %d verificou posicoes %d a %d. Achou: %d\n", k, inicio, fim, resul[k]);

            exit(0);
        }
    }

    for (i = 0; i < N; i++){
        pid = wait(&status);
    }

    printf("\n");

    int achou = 0;
    for (k = 0; k < N; k++){
        if (resul[k] != -1){
            printf("Chave %d encontrada na posicao %d no processo %d\n", CHAVE, resul[k], k);
            achou = 1;
        }
        else{
            printf("Chave %d não foi encontrada no processo %d\n", CHAVE, k);
        }
    }
    if (!achou){
        printf("Chave %d nao encontrada no vetor.\n", CHAVE);
    }
    shmdt (vetor);
    shmdt (resul);

    shmctl (segV, IPC_RMID, 0);
    shmctl (segR, IPC_RMID, 0);

    return 0;
}

REFLEXAO:
O vetor de dados (segV) e o vetor de resultados (segR) sao criados e
anexados pelo processo PAI antes do laco de fork, pela mesma razao do
Exercicio 1: assim, cada um dos 4 processos filhos ja nasce enxergando
os mesmos ponteiros "vetor" e "resul", sem precisar refazer shmget/shmat.
O vetor de 20 posicoes e dividido em 4 fatias de 5 elementos (fatia =
TAM/N); cada filho k varre somente o intervalo [k*fatia, (k+1)*fatia) e,
se encontrar a chave, grava o INDICE onde encontrou em resul[k]
(inicializado com -1, usado como "sentinela" de nao encontrado) e
interrompe a busca com break, ja que so precisamos de uma ocorrencia
por fatia.

A saida confirma que a chave 42 aparece em 3 das 4 fatias (posicoes 0, 6
e 18) e nao aparece na fatia do processo 2 (posicoes 10 a 14) - o que
esta correto ao conferir o vetor de entrada, ja que os valores 42
aparecem nos indices 0, 6 e 18 do array "valores".

Um ponto interessante sobre a ORDEM da saida: os filhos imprimem na
ordem 0, 1, 2, 3 nesta execucao, mas essa ordem NAO e garantida pelo
fork() - depende de qual processo o escalonador do sistema operacional
decide executar primeiro em cada instante, e do tempo que cada filho leva
para concluir sua busca (por exemplo, o filho que encontra a chave na
primeira posicao da sua fatia termina mais rapido que um filho que
precisa varrer a fatia inteira sem encontrar nada). Rodando o mesmo
programa novamente, a ordem de impressao pode ser diferente.

EXERCICIO 4 - Multiplicacao multi-processo
===============================================================================

ENUNCIADO:
Faca um programa que:
- Tenha um processo pai que abre dois blocos de memoria compartilhada,
  m1 e m2.
- Crie dois processos filho (use exec), P1 e P2: estes tambem fazem
  attach em m1 ou m2 respectivamente.
- Cada um da um sleep() randomico e escreve um valor int na area
  compartilhada dele, e avisa o processo pai que um novo valor foi
  gerado, escrevendo tb um numero de sequencia.
- O pai fica em loop verificando se houve um novo valor. Apenas quando
  ambos P1 e P2 geraram um novo valor, o pai imprime o produto dos
  valores gerados por P1 e P2.

CODIGO FONTE (ex4.c) - processo pai:
-------------------------------------------------------------------------------
#include <stdio.h>
#include <stdlib.h>
#include <sys/ipc.h>
#include <sys/shm.h>
#include <sys/stat.h>
#include <unistd.h>
#include <sys/wait.h>

typedef struct {
    int valor;  /* ultimo valor gerado pelo filho */
    int seq;    /* numero de sequencia, incrementado a cada novo valor */
} Area;


int main(int argc, char* argv[]){
    int seg1, seg2;
    Area *m1, *m2;
    int status;
    pid_t pid1, pid2;
    char str_seg1[16], str_seg2[16];

    seg1 = shmget(IPC_PRIVATE, sizeof (Area), IPC_CREAT | IPC_EXCL | S_IRUSR | S_IWUSR);
    seg2 = shmget(IPC_PRIVATE, sizeof (Area), IPC_CREAT | IPC_EXCL | S_IRUSR | S_IWUSR);

    m1 = (Area *)shmat(seg1, 0, 0);
    m2 = (Area *)shmat(seg2, 0, 0);

    m1->valor = 0;
    m1->seq = 0;
    m2->valor = 0;
    m2->seq = 0;

    sprintf(str_seg1, "%d", seg1);
    sprintf(str_seg2, "%d", seg2);

    pid1 = fork();

    if (pid1 < 0){
        perror("fork p1");
        exit(1);
    }
    else if (pid1 == 0){
        execl("./ex4filhos", "filho", str_seg1, "P1", NULL);

        perror("execl p1");
        exit(1);
    }

    pid2 = fork();

    if (pid2 < 0){
        perror("fork p2");
        exit(1);
    }
    else if (pid2 == 0){
        execl("./ex4filhos", "filho", str_seg2, "P2", NULL);

        perror("execl p2");
        exit(1);
    }

    int ult_seq1 = 0, ult_seq2 = 0;
    int produtos_impressos = 0;

    while(produtos_impressos < 3){
        if(m1->seq > ult_seq1 && m2->seq > ult_seq2){
            printf("[PAI] produto disponivel: %d * %d = %d\n",
                    m1->valor, m2->valor, m1->valor * m2->valor);

            ult_seq1 = m1->seq;
            ult_seq2 = m2->seq;
            produtos_impressos++;
        }

        usleep(1000);
    }

    waitpid(pid1, &status, 0);
    waitpid(pid2, &status, 0);

    printf("[PAI] fim. %d produtos impressos.\n", produtos_impressos);

    shmdt(m1);
    shmdt(m2);
    shmctl(seg1, IPC_RMID, 0);
    shmctl(seg2, IPC_RMID, 0);

    return 0;
}

CODIGO FONTE (ex4filhos.c) - programa executado via exec por P1 e P2:
-------------------------------------------------------------------------------
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/ipc.h>
#include <sys/shm.h>
#include <sys/stat.h>

typedef struct {
    int valor;
    int seq;
} Area;

int main(int argc, char *argv[]) {
    if (argc < 3) {
        fprintf(stderr, "uso: %s <id_segmento> <nome>\n", argv[0]);
        exit(1);
    }

    int id = atoi(argv[1]);
    const char *nome = argv[2];

    Area *area = (Area *)shmat(id, 0, 0);
    if (area == (void *) -1){
        perror("shmat");
        exit(1);
    }

    srand(getpid());

    for (int i = 0; i < 3; i++){
        int tempo = (rand() % 2) + 1;
        sleep(tempo);

        int valor = (rand() % 20) + 1;

        area->valor = valor;
        area->seq = area->seq + 1;

        printf("[%s] gerou valor %d (seq %d) apos dormir %ds\n",
            nome, valor, area->seq, tempo);
    }

    shmdt(area);

    return 0;
}

REFLEXAO:
Este exercicio e diferente dos anteriores porque exige o uso de exec(),
o que muda a forma como a memoria compartilhada e propagada aos filhos.
Nos Exercicios 1 e 3, os filhos (criados so com fork()) HERDAVAM
automaticamente os ponteiros ja anexados (shmat) pelo pai. Aqui isso NAO
funciona: o exec() SUBSTITUI COMPLETAMENTE a imagem de memoria do
processo filho (codigo, dados, pilha, e qualquer shmat() anterior),
entao P1 e P2, apos o execl(), precisam refazer o proprio shmat() do
zero. Para isso, o id do segmento (retornado por shmget() no pai) e
convertido para string com sprintf() e passado como ARGUMENTO DE LINHA
DE COMANDO no execl() - e o programa ex4filhos.c, ao iniciar, converte
esse argumento de volta para int com atoi() e faz seu proprio shmat(id,
0, 0).

A sincronizacao entre pai e filhos e feita por um NUMERO DE SEQUENCIA
(campo seq da struct Area), em vez de um simples flag booleano: cada
filho escreve primeiro o "valor" e SO DEPOIS incrementa o "seq" -
essa ordem evita que o pai leia um seq novo mas ainda encontre um valor
desatualizado (uma condicao de corrida). O pai guarda, para cada filho,
o ultimo seq que ja processou (ult_seq1/ult_seq2) e so imprime um novo
produto quando AMBOS os seq avancaram desde a ultima impressao - por
isso a saida so mostra o primeiro produto (10*16=160) depois que tanto
P1 quanto P2 ja tinham gerado ao menos um valor novo, mesmo que um deles
tivesse terminado sua primeira rodada antes do outro.

O laco do pai (while) e um busy-wait / polling: ele fica constantemente
comparando m1->seq/m2->seq com os ultimos valores vistos, com um
usleep(1000) so para nao consumir 100% de um nucleo de CPU. Isso resolve
o problema pedido no enunciado, mas gasta ciclos de CPU em verificacoes
repetidas; uma alternativa mais eficiente (fora do escopo deste
exercicio) seria usar semaforos ou sinais para o pai ficar bloqueado at
e ser explicitamente avisado por P1/P2.

Por fim, note que o buffer de saida de cada processo so e liberado
quando aquele processo termina: por isso, na saida, aparecem primeiro
TODAS as 3 linhas de P1, depois TODAS as 3 linhas de P2, e so entao as
linhas do PAI - mesmo os eventos tendo ocorrido intercalados no tempo
real (confirmado pelos numeros de sequencia e pelos tempos de sleep
registrados). Isso e o mesmo efeito de buffer de stdio observado em
exercicios anteriores do Lab 1.
